# AutoLedger 手机验收清单

适用设备：小米 15 Pro，HyperOS 3（Android 17）。目标是在真机上确认「装得上、收得到、记得对、不联网」。全程约 20 分钟，建议按顺序做，遇到问题先看最后的「排障」。

> 文中路径以 HyperOS 3 为准；不同小版本可能把入口放在「设置 → 应用设置」或「手机管家」两处，找不到时两个地方都翻一下。

## 一、安装

APK 来源二选一：

1. **本机文件**：打开「文件管理」，进入 `内部存储/Download/DSH-Go/AutoLedger/AutoLedger-0.2.0.apk`，点击安装。
2. **GitHub Release**：打开仓库的 Releases，选择 tag 为 `apk-<run_number>` 的版本，下载资产 `autoledger.apk` 后安装。

首次从文件管理器安装时，系统会拦截并提示「禁止安装未知应用」：

- 点提示里的「设置」→ 打开「允许来自此来源的应用」→ 返回 → 重新点 APK。
- 若已装过旧版本且提示「应用未安装 / 签名不一致」，先卸载旧版再装（卸载会清空本地账单，卸载前先在「设置 → 导出」备份 CSV）。

安装完成后先不要急着用，进入下一步开启权限。

## 二、首次启动引导（6 项）

打开 AutoLedger，会进入「开启自动记账」引导页。每张卡片右侧有状态标签，页面**每 2 秒自动刷新**，从系统设置返回后不用手动点刷新。建议按页面提示的顺序：通知使用权 → 无障碍 → 通知权限 → 自启动 / 省电策略 → 最近任务锁定。

### 1. 通知使用权

- **怎么开**：点卡片上的按钮，直接跳到系统的「通知使用权」列表；找到 AutoLedger，打开开关，弹窗点「允许」。
- **在哪开**（手动）：设置 → 应用设置 → 特殊权限 → 通知使用权；部分版本在 设置 → 通知与控制中心 → 通知使用权。
- **开完回来自检应显示**：该项状态变为「已授权」；「设置 → 权限与自检」里的「通知监听连接」显示「服务已连接，正在接收支付通知」。

### 2. 无障碍服务

- **怎么开**：点按钮跳到无障碍设置 → 「已下载的应用 / 已安装的应用」→ AutoLedger → 打开开关 → 阅读系统提示后点「允许」。
- **在哪开**（手动）：设置 → 无障碍 → 已下载的应用 → AutoLedger；HyperOS 部分版本在 设置 → 更多设置 → 无障碍。
- **开完回来自检应显示**：该项变为「已授权」。这一项只是兜底，不开也能靠通知记账，但通知被折叠时会漏。

### 3. 通知权限

- **怎么开**：点按钮会直接弹系统权限框，选「允许」。
- **在哪开**（手动）：设置 → 应用设置 → 应用管理 → AutoLedger → 通知管理 → 允许通知（并保留「记账提醒」「服务状态」两个渠道）。
- **开完回来自检应显示**：该项变为「已授权」。这是 App 给你发入账提醒、预算提醒的前提，关掉不影响记账但收不到提醒。

### 4. 自启动

- **怎么开**：点按钮尝试跳转小米自启动页；跳不过去就按下面的手动路径。
- **在哪开**（手动）：设置 → 应用设置 → 应用管理 → AutoLedger → 自启动（有的版本叫「自启动管理」）；或 手机管家 → 应用管理 → 权限 → 自启动。
- **开完回来自检应显示**：仍显示「未知」，并注明「系统不提供查询接口，请在设置里确认已允许自启动」。**这是正常的**，系统没有公开 API，只能靠你自己确认。

### 5. 省电策略无限制

- **怎么开**：点按钮会直接弹「忽略电池优化」授权框，选「允许」。
- **在哪开**（手动）：设置 → 应用设置 → 应用管理 → AutoLedger → 省电策略 → 无限制；或 手机管家 → 电池 → 应用智能省电 → AutoLedger → 无限制。
- **开完回来自检应显示**：该项变为「已授权」。这是「放一晚还能自动记账」的关键。

### 6. 最近任务锁定

- **怎么开**：打开 AutoLedger 后上滑进入最近任务，长按 AutoLedger 卡片（或下拉卡片），点「锁定 / 小锁图标」。
- **在哪开**（手动）：最近任务界面，系统设置里没有对应开关。
- **开完回来自检应显示**：仍显示「未知」，并注明「系统不提供查询接口，请在最近任务里手动加锁」。同样**属于正常**，卡片上出现小锁即成功。

6 项过完后点底部「进入 AutoLedger」。以后想复查，走「设置 → 权限与自检」或「设置 → 重新走一遍开启引导」。

## 三、功能验收清单

逐项打勾，括号里是通过标准。

### 基础记账

- [ ] **手动记一笔**：账单页点「记一笔」，填金额（如 12.50）、商户、分类，保存后出现在当天列表，统计页本月支出随之增加。
- [ ] **支付宝自动入账**：用支付宝付一笔（如美团外卖），**5 秒内**账单页出现该笔，金额一致、分类为「餐饮」；通知栏出现「已记账 ¥12.50」。
- [ ] **微信一笔**：微信支付后同样自动入账，来源显示为微信。
- [ ] **云闪付一笔**：云闪付支付后自动入账。
- [ ] **营销通知不入账**：在支付宝里触发一条营销 / 活动通知，账单页不新增记录；进「设置 → 识别日志」，筛选「已过滤」，能看到该条且 `outcome=FILTERED_MARKETING`。
- [ ] **同一笔不重复**：对同一笔交易连续触发两次上报（通知 + 无障碍，或重复通知），账单里只有一条；识别日志出现「已合并」（`DUPLICATE_MERGED`）。
- [ ] **退款冲抵**：先付一笔，再对同一商户发起等额退款，原支出行下方出现「已退 ¥x」，统计页支出相应减少。
- [ ] **待确认队列**：制造一条低置信度记录（例如微信卡片通知不带金额），它会进入「待确认」而不是直接入账；展开能看到通知原文，点「确认入账」后计入统计，点「丢弃」则保留记录但不计入。

### 预算与统计

- [ ] **预算阈值通知**：在「预算」页设置一个月总预算，消费到约 80% 时收到「本月预算已用 x%」，到 100% 时收到「本月预算已超支」；同一个月各只提醒一次。
- [ ] **统计图表**：统计页显示本月支出 / 收入 / 结余、分类占比环形图、近 6 个月趋势；切换月份数字跟着变；打开「红包计入收支」后数字重算。

### 导出与桌面

- [ ] **CSV 导出**：设置 → 导出 CSV，弹出系统分享面板，选微信「文件传输助手」或邮件发出，在对方打开能看到表头和金额。
- [ ] **XLSX 导出**：同样导出 XLSX 并在微信 / 邮件 / WPS 中打开，金额列可直接求和。
- [ ] **桌面小组件**：桌面长按空白处 → 添加小部件 → AutoLedger「今日支出」（4x2）→ 放上桌面后显示今日支出、本月累计、预算剩余；再记一笔，组件应立即刷新。

### 稳定性

- [ ] **后台放一晚**：锁屏放置 8 小时以上（不充电也可以），第二天早上直接用支付宝付一笔，仍能在 5 秒内自动入账。若失败，回看「自启动」「省电策略」「最近任务锁定」三项。

## 四、排障

### 通知不触发 / 突然不记账

1. 打开「设置 → 权限与自检」，看「通知监听连接」：显示「服务未连接，系统可能已解绑」就是被系统解绑了。
2. 点「重新绑定监听」。若仍连不上，去系统「通知使用权」里把 AutoLedger 关掉再打开。
3. 确认 HyperOS 没把它当后台应用清理：自启动允许、省电策略「无限制」、最近任务已锁定。
4. 确认支付宝 / 微信 / 云闪付的通知本身没有被你关掉（App 只能读已经出现的通知）。
5. 还不行就看「识别日志」：没有日志 = 通知没进来（权限 / 绑定问题）；有 `UNPARSED` = 通知文案不在解析规则里，可把原文记下来反馈。

### 无障碍识别不到

1. 设置 → 无障碍 → 已下载的应用，确认 AutoLedger 的服务仍是开启状态（有些系统会在重启或省电清理后自动关掉）。
2. 无障碍只在支付结果页停留时生效，且 2 秒内只处理一次；付款后别立刻退出页面。
3. 部分自定义控件读不到文本属于已知限制，此时以通知通道为准，不影响主要流程。

### APK 装不上

- **「应用未安装」/「签名不一致」**：新旧 APK 签名不同。先卸载旧版再装；卸载会清空账单，务必先导出备份。
- **「解析包时出现问题」**：下载不完整，重新下载 `autoledger.apk` 再试。
- **「空间不足」**：清理存储后重试。

### 金额是 0 / 记成了待确认

微信部分支付卡片通知不带金额，App 会先存为「待确认」并提示「有一笔待补金额」，点开补金额并确认即可。

## 五、隐私自查

确认这个 App 真的没有联网能力：

**方式 A（adb，最直接）**：

```bash
adb shell dumpsys package com.nicktj.autoledger | grep -i permission
```

输出里应只看到 `POST_NOTIFICATIONS`、`RECEIVE_BOOT_COMPLETED`、`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` 等，**不应出现 `android.permission.INTERNET`**，也不应有 `ACCESS_NETWORK_STATE` / `FOREGROUND_SERVICE` / `WAKE_LOCK`。

**方式 B（不接电脑）**：

- 设置 → 应用设置 → 应用管理 → AutoLedger → 权限，逐个翻看，确认没有「网络 / 联网」类权限。
- 或在「设置 → 权限与自检」里核对 App 自己列出的权限项。

**数据边界**：账单只在本机数据库；识别日志里的通知原文默认保留 30 天（设置里可调 1–90 天），过期自动清理；`allowBackup=false`，不会进入云备份。卸载 App 会连同数据一起删除，重要账单请先导出。
